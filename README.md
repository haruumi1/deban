# 出番

ピアノ・ダンス・バレエなどの発表会の**出演順**を、演目と出演者を貼るだけで自動で組むツール。
掛け持ちの人が連続しないよう「早着替えの間隔」を空けて並べ替えます。

**▶ （公開前）想定 URL: https://haruumi1.github.io/deban/**

> [コマ割り](https://haruumi1.github.io/komawari/)（軽音合宿の練習わりふり）の姉妹ツール。
> 同じ「掛け持ちの衝突を解く」核を、**部屋×コマの割り当て**から**1列の出演順**へ展開したもの。

## 特徴

- 登録不要・インストール不要。ブラウザで開いて貼るだけ
- 名前は外部に送信・保存されません（すべてブラウザ内で計算）
- **並べたい順（学年順など）をそのまま貼ればOK** … 掛け持ちの被りだけ最小の入れ替えで直します
- 早着替えが厳しい人を自動で検出して警告（掛け持ち一覧）
- 所要時間 `[3:00]` を書けば累計時刻・休憩の目安も計算
- 結果は「プログラムをコピー」でスプレッドシート / Word / Google ドキュメントにそのまま貼れる。画像・共有リンク・LINE にも対応

## 仕組み

掛け持ち（同じ人が複数の演目に出る）を「同じ人の出演を最低 N 組あけて並べる」という
**最小間隔つき並べ替え（sequencing with minimum separation）**として解いています。

- 探索はバックトラッキング。候補は **①入力順**（先生の意図した並びを最小改変）→ **②掛け持ちの多い順**（堅牢性）の順で試行
- 演目数に対して掛け持ちが多すぎて間隔を確保できないときは、**自動で間隔を緩め、ボトルネックになっている人を名指しで報告**します（＝汚い現実を飲み込んで必ず答えを返す）
- 間隔 0（隣り合わせ可）は常に解けるため、エラーで終わらず必ずプログラムが出ます

検証は `node test_solver.js`（分離制約・自動緩和・固定・異常系＋ランダム fuzz 200 ケース）。

## なぜ作ったか（設計メモ）

- **コマ割りの弱点を埋める2つ目のビーチヘッド。** コマ割り（軽音合宿）は低頻度・無収入の学生が相手で、課金につながりにくい。発表会は **既に発表会にお金を払う小規模事業者（教室）** が相手で、支払い意欲が一段上。
- **需要は実証済み。** 英語圏には同種の有料製品が複数ある（RCM AutoSeq＝$39.95 買い切りで「指定組数あけて自動生成」、RecitalReady の "Costume Change Cushion"、The Studio Director の連続出演チェッカー等）。＝「誰が金を払うのか」がコマ割りより明確。
- **日本語市場は空白。** 日本語で見つかるのは「ランダム順くじ」と「Canva 等のプログラム装飾」だけで、**制約を解くツールが無い**。英語勢はいずれも重い教室管理スイート（チケット・衣装・請求込み・英語・米国ダンス文化前提）。
- **だから堀はアルゴリズムではない。** 勝ち筋は **〈日本語ネイティブ＋名簿セットアップ不要の貼って即＋¥価格＋軽量〉が、重い英語スイートに勝つ**こと。コマ割り最大の資産（名簿不要・貼って即の UX）を、そのまま差別化の刃にしている。
- **不都合な真実。** 発表会も年1〜2回で**低頻度**という弱点はコマ割りと共通。これは「天井を破る」一手ではなく、「より良いビーチヘッドで、実在事業者を相手に課金実験する」一手。天井を破るのは将来の重い層（リハ表・当日進行・名簿・決済）への接続で、その入口として発表会は軽音より筋が良い。
